# Uzochukwu Akunedozi Foundation

A digital platform for the Uzochukwu Akunedozi Foundation, a Nigeria-based NGO focused on children, education, health, empowerment, community development, and poverty alleviation.

## Planned platform

- Public foundation website
- Programmes and project pages
- Online donations (Flutterwave and Paystack)
- Donation receipts and transaction history
- Volunteer applications
- Events, impact stories, and media gallery
- Contact and newsletter forms
- Secure administration dashboard

## Technology

- Next.js and TypeScript
- Supabase (Postgres, Auth, Storage)
- Vercel hosting
